Free, privacy respecting replacements for mainstream apps. No ads, no tracking.

Office Suite

Microsoft Office / Google Workspace LibreOffice

A completely free offline office suite with Writer, Calc, and Impress. Highly compatible with Microsoft formats.

Modern Office Suite

Microsoft 365 OnlyOffice

A cleaner, more modern interface with excellent compatibility for DOCX, XLSX, and PPTX files. Can be self hosted.

Note Taking

Notion / Evernote Obsidian / AppFlowy

Obsidian for local markdown note taking. AppFlowy for databases and kanban boards.

Task and Time Management

Todoist / Toggl Super Productivity

An open source task manager and time tracker with Jira and GitHub integration.

Automation

Zapier / IFTTT Huginn / n8n

Run automated workflows on your own terms without vendor lock in.

Image Editing

Adobe Photoshop GIMP

A long standing free image editor. Recent updates added non destructive layers and improved format compatibility.

Digital Painting

Adobe Photoshop / Corel Painter Krita

The best free option for digital painting, illustration, and concept art with an excellent brush engine.

Vector Graphics

Adobe Illustrator Inkscape

A free vector graphics editor for creating logos, illustrations, and scalable designs.

UI/UX Design

Figma Penpot

An open source design and prototyping platform built on open web standards.

Photo Management

Google Photos PhotoPrism / Ente Photos

PhotoPrism for private, self hosted photo management with AI tagging. Ente Photos for end to end encrypted cloud storage.

Raw Processing

Adobe Lightroom Darktable / RawTherapee

Professional grade raw image processing and library management.

Video Editing

Adobe Premiere Pro Kdenlive / DaVinci Resolve

Kdenlive is fully open source. DaVinci Resolve is proprietary but offers a powerful free tier for editing and color grading.

Video Streaming

YouTube Premium NewPipe / Grayjay

Watch videos ad free, play background audio, and download clips without a Google account.

Media Player

Proprietary Players VLC Media Player

A trusted, open source tool that plays any audio or video format without tracking you.

Music Streaming (Self Hosted)

Spotify / Apple Music Navidrome / Funkwhale

Self hosted music servers that let you stream your personal collection to any device. Use clients like Feishin for playback.

Messaging

WhatsApp Signal

The gold standard for end to end encrypted messaging and voice calls with minimal metadata collection.

Maximum Privacy Messaging

WhatsApp / Telegram SimpleX

Uses a decentralized architecture that requires no personal identifiers, not even a phone number. The invite link system can be cumbersome.

Email Client

Gmail / Outlook (desktop) Thunderbird

A powerful, ad free desktop email client that works with any provider and includes a built in calendar.

Video Conferencing

Zoom / Microsoft Teams Jitsi Meet

Browser based, encrypted video conferencing that requires no account creation or software installation.

Password Management

1Password / LastPass Bitwarden / KeePassXC

Free, secure, and open source password management across all your devices.

Two Factor Authentication

Google Authenticator Aegis Authenticator

A secure, encrypted alternative for managing 2FA codes. Supports biometric unlock and encrypted backups.

App Store Client

Google Play Store Aurora Store

An open source client that lets you download apps from the Play Store anonymously.

File Manager

Paid Android File Managers Fossify File Manager

A lightweight, ad free file manager focused on speed and simplicity without unnecessary permissions.

Remote Desktop

TeamViewer RustDesk

Free, fast, and secure remote desktop access you can self host.

PDF Editing

Adobe Acrobat Okular / PDF Arranger

View, annotate, and edit PDFs without subscription fees or telemetry.

Web Browser

Google Chrome Firefox / Brave

Prevents cross site tracking and does not feed your browsing history into an advertising ecosystem.

Budgeting

Mint / YNAB Actual Budget / Firefly III

Local first and open source, allowing you to track household income and expenses without selling your financial data.

Portfolio Tracking

Mainstream Aggregators Ghostfolio

Open source wealth management software to track investments without handing over credentials to third parties.

Navigation

Google Maps Organic Maps / OsmAnd

Built on OpenStreetMap data with fully offline routing and no location tracking. Ideal for hiking and road trips. Lacks real time traffic data.

Cloud Storage

Google Drive / Dropbox Nextcloud

A self hosted cloud storage solution that gives you full control over your files, contacts, calendars, and more.

File Sync

Google Drive / Dropbox Syncthing

Continuous peer to peer file synchronization. Data syncs directly between your devices without touching a third party server.

Article Saving

Pocket Wallabag

Self hosted article archiving and reading list management.

Podcasts

Spotify / Proprietary Apps AntennaPod

A completely free, open source podcast player for Android. Supports any RSS feed, offline downloads, and has no algorithmic interference or ads.

Code Hosting

GitHub Forgejo / Gitea

Lightweight, self hosted Git services that give you full control over your repositories.

Code Editor

Visual Studio Code VSCodium

A telemetry free, open source build of the VS Code editor.

Activity Tracking

Strava OpenTracks

GPS activity tracking for Android that stores data locally and exports to standard formats.

Most of these apps are available through F Droid (an open source app store) or directly from the developers websites. Click on any app name to search and download.
